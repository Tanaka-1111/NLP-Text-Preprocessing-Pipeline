# 🧠 NLP Text Preprocessing & Classification Pipeline

自然言語処理（NLP）における非常に重要なプロセスである**「データの前処理（数値化・パディング）」**から、ニューラルネットワークを用いたテキスト分類までを一連のパイプラインとして実装したJupyter Notebookプロジェクトです。

本プロジェクトで構築した前処理ロジックは、**通常のニューラルネットワーク（DNN）から時系列モデル（RNN）、さらには発展的なモデルまで幅広く応用可能**な汎用性の高い設計となっています。

## 🌟 プロジェクト概要
文字列であるテキストデータをAIモデルが計算できる形に最適化し、分類モデルに投入するまでの全工程を網羅しています。
機械学習において「データの質」はモデルの精度に直結するため、特にデータの形を綺麗に整える前処理（Pre-processing）の工程に注力して「改訂版」としてブラッシュアップしました。

## ⚙️ 実装している主な処理・パイプライン

### 1. 汎用的なデータの前処理（Text Preprocessing）
* **テキストの数値化（Tokenization / Embedding準備）**: 文字列をモデルが演算可能なインデックス（数値）の並びへと変換します。
* **パディング処理（Padding）**: 入力層のノード数が固定されているニューラルネットワークの特性に合わせ、長さの異なるテキストデータを一定の長さに揃える重要な処理です。

### 2. ニューラルネットワーク構造（Model Architecture）
Keras / TensorFlow を用いて、テキスト特徴を効率よく学習するレイヤー構造を採用しています。
* **Embedding層**: 数値化された単語を、高次元の分散表現（ベクトル）に変換し、単語同士の意味の近さを表現します。
* **ネットワーク層（柔軟な切り替えが可能）**:
  * **RNN（SimpleRNN層）を使用する場合**: 単語の並び順（時系列の文脈）を保持しながら順番に学習します。
  * **通常のDNN（Dense層）を使用する場合**: パディングされた特徴量を一括で処理し、高速な分類を行います。
* **Dense層（全結合層 / 出力層）**: 最終的な予測結果やクラス分類を出力します。
